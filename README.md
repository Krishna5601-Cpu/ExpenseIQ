# ExpenseIQ 💸

**ExpenseIQ** is an AI-powered expense tracker built with Flask. It lets you log daily expenses, set monthly budgets, visualize spending with charts, and get AI-generated financial insights powered by Google Gemini.

---

## ✨ Features

- **Expense Management** -> add, edit, and delete expenses with amount, category, description, and date.
- **Budget Planner** -> set an overall monthly budget and per-category budgets (food, travel, shopping, health, bills, entertainment).
- **Smart Insights** -> automatic, rule-based analytics: spending totals, category breakdowns, busiest spending day, budget usage warnings, and detected spending patterns (e.g. frequent food delivery or subscriptions).
- **AI Insights** -> on-demand, personalized financial advice generated by Gemini, returned as four structured, actionable insights.
- **Charts** -> auto-generated pie chart (expense distribution) and line chart (spending trend) rendered on the dashboard.
- **Dark Mode** -> toggleable light/dark UI built with Tailwind CSS.
- **Custom Error Pages** -> friendly 404 and 500 error handlers.

## ⚙️ Configuration

Environment variables are loaded from a `.env` file at the project root (via `python-dotenv`). Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

| Variable         | Description                              | Default                           |
| ---------------- | ---------------------------------------- | --------------------------------- |
| `SECRET_KEY`     | Flask secret key                         | `change-this-secret-key`          |
| `DATABASE_URL`   | SQLAlchemy database URI                  | `sqlite:///instance/expenseiq.db` |
| `GEMINI_API_KEY` | Google Gemini API key for AI insights    | -> (required for AI features)      |
| `GEMINI_MODEL`   | Gemini model used for insight generation | `gemini-2.5-flash`                |

Other application settings (max description length, max category length, max expense amount, default currency `₹`, date format) are defined directly in `config.py`.

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- A Google Gemini API key (optional, only needed for AI Insights)

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd expenseiq

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Set up environment variables
cp .env.example .env
# then edit .env with your values
```

### Run the app

```bash
python run.py
```

The app will be available at **http://127.0.0.1:5000**.

The database (SQLite) and `budgets.json` are created automatically on first run.

## 🧭 Usage

- **Dashboard (`/`)** -> view recent expenses, spending charts, and smart insights. Add a new expense from the sidebar form.
- **Edit Expense (`/edit/<id>`)** -> update an existing expense.
- **Delete Expense (`/delete/<id>`)** -> remove an expense.
- **Budget Planner (`/budget`)** -> set your overall and per-category monthly budgets.
- **AI Insights (`/ai-insights`)** -> click **Generate** on the dashboard to fetch four AI-generated financial insights (requires a valid `GEMINI_API_KEY`).

---

## 🧠 How AI Insights Work

The `AIService` sends your expense history to Gemini with a system prompt instructing it to return **exactly four** insights covering:

1. Overall spending trend
2. A wasteful spending habit
3. A concrete saving suggestion
4. A future budget recommendation

Responses are validated against a Pydantic schema (`InsightsResponse`) to guarantee structured, parseable output. If no API key is configured or generation fails, the app gracefully falls back to a friendly message instead of erroring out.

---

## 📊 Analytics & Insights (Rule-Based)

Independent of AI, `AnalyticsService` computes:

- Total spending and category-wise totals/percentages
- Highest spending category and busiest spending day
- Budget usage and overspending alerts (per category and overall)
- Pattern detection from expense descriptions (e.g. food delivery, transport, subscriptions)
